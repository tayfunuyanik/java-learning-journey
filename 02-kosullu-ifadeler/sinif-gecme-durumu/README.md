# Ders Notu Ortalama Hesaplama

Java ile Matematik, Fizik, Türkçe, Kimya ve Müzik derslerinin not ortalamasını hesaplayan basit konsol uygulaması.

## Özellikler

- 0 ile 100 arasındaki geçerli notları hesaba katar.
- Geçersiz notları ortalamaya dahil etmez.
- Geçerli notların ortalamasını hesaplar.
- Ortalama 55 ve üzerindeyse geçme, altındaysa kalma durumunu gösterir.
