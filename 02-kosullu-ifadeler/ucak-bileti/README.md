# Uçak Bileti Hesaplama

Java ile mesafe, yaş ve yolculuk tipine göre uçak bileti fiyatını hesaplayan konsol uygulaması.

## Özellikler

- Geçerli mesafe, yaş ve yolculuk tipi kontrolü yapar.
- Yaşa göre indirim uygular.
- Gidiş-dönüş seçiminde %20 indirim uygular ve iki yönün toplam tutarını hesaplar.
