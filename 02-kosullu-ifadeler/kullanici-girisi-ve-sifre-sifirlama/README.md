# Kullanıcı Girişi ve Şifre Sıfırlama

Java ile kullanıcı şifresini kontrol eden ve yanlış şifre durumunda şifre sıfırlama işlemi sunan konsol uygulaması.

## Özellikler

- Mevcut şifre ile giriş kontrolü
- Yanlış şifre durumunda şifre sıfırlama seçeneği
- Yeni şifrenin eski şifreyle aynı olmasını engelleme
- Yeni şifreyi tekrar girerek doğrulama
- Hatalı seçim kontrolü
