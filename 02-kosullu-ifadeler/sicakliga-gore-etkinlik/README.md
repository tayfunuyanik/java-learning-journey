# Sıcaklığa Göre Etkinlik Önerisi

Java ile kullanıcıdan alınan hava sıcaklığına göre etkinlik önerileri sunan basit konsol uygulaması.

## Sıcaklık Aralıkları

- 5 dereceden düşük: Kayak veya evde film izleme
- 5 ile 15 derece arası: Sinema veya kafede vakit geçirme
- 15 ile 25 derece arası: Piknik veya yürüyüş
- 25 dereceden yüksek: Yüzme veya dondurma yeme
