# Recursive Asal Sayı Kontrolü

Kullanıcıdan alınan pozitif tam sayının asal olup olmadığını recursive metot kullanarak kontrol eden Java konsol uygulaması.

## Hedef

Bir sayının bölenlerini recursive çağrılarla kontrol etmek ve sonucu `boolean` olarak üretmek.

## Kullanılacak Konular

- Recursive metotlar
- Temel durum
- `boolean` dönüş türü
- Mod operatörü
