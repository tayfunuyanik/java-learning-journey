# Recursive Üs Hesabı

Kullanıcının girdiği taban ve üs değerine göre sonucu recursive metot ile hesaplayan Java konsol uygulaması.

## Hedef

Döngü kullanmadan, üs değeri sıfıra ulaştığında sona eren recursive hesaplama kurmak.

## Kullanılacak Konular

- Recursive metotlar
- Temel durum
- Parametre ve dönüş değeri
