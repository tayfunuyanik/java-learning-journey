# Palindrom Sayılar

Kullanıcıdan alınan bir sayının tersten okunuşunun kendisine eşit olup olmadığını kontrol eden Java konsol uygulaması.

## Hedef

Sayıyı ters çevirme işlemini ayrı bir metotta kurmak ve sonucu `boolean` olarak döndürmek.

## Kullanılacak Konular

- Parametre alan metotlar
- `boolean` dönüş türü
- Döngü ve basamak işlemleri
