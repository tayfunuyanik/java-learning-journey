# Desene Göre Metot Oluşturma

Kullanıcıdan alınan sayıyı 0 veya negatif olana kadar 5 azaltan, ardından başlangıç değerine kadar 5 artıran recursive Java konsol uygulaması.

## Hedef

Çıkarma ve geri dönüş aşamalarını döngü kullanmadan tek recursive metotta yönetmek.

## Kullanılacak Konular

- Recursive metotlar
- Temel durum
- Koşullu ifadeler
- Metot çağrısı sırasında değerlerin geri dönüşü
