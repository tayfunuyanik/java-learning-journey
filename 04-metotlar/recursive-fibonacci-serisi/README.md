# Recursive Fibonacci Serisi

Kullanıcıdan alınan eleman sayısına göre Fibonacci serisini recursive metot kullanarak üreten Java konsol uygulaması.

## Hedef

Fibonacci dizisinin her elemanını, metodun kendisini çağırdığı recursive yapı ile hesaplamak.

## Kullanılacak Konular

- Recursive metotlar
- Temel durum
- `int` veya `long` dönüş türü
