# Taksimetre Hesaplama

Java ile gidilen mesafeye göre taksi ücretini hesaplayan konsol uygulaması.

## Uygulama Kuralları

- Kilometre başına ücret: 2.20 TL
- Taksimetre açılış ücreti: 10 TL
- Minimum ödenecek tutar: 20 TL

## Kullanılan Konular

- Scanner ile kullanıcı girdisi
- while döngüsü
- if / else koşulları
- double veri tipi
