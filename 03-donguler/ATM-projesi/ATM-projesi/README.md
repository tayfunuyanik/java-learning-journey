# ATM Projesi

Java ile geliştirilmiş, konsol üzerinden çalışan basit bir ATM uygulamasıdır.

## Özellikler

- Kullanıcı adı ve şifre ile giriş yapılır.
- Kullanıcının üç giriş hakkı vardır.
- Üç hatalı girişten sonra hesap bloke edilir.
- Para çekme, para yatırma ve bakiye sorgulama işlemleri yapılabilir.
- Para çekme ve yatırma tutarları için sayısal ve pozitif değer kontrolü bulunur.
- ATM işlemleri `switch-case` yapısı ile yönetilir.

## Giriş Bilgileri

- Kullanıcı adı: `patika`
- Şifre: `dev123`

## Kullanılan Konular

- `Scanner`
- `while` döngüsü
- `if / else`
- `switch-case`
- `break` ve `continue`
