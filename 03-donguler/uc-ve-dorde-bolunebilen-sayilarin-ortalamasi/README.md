# 3 ve 4'e Bölünebilen Sayıların Ortalaması

Kullanıcının girdiği sayıya kadar olan sayılar arasından hem 3'e hem de 4'e tam bölünebilen sayıların ortalamasını hesaplayan Java konsol uygulaması.

## Kullanılan Konular

- `for` döngüsü
- `if-else` koşulları
- Mantıksal `&&` operatörü
- Mod (`%`) operatörü
- `Scanner` ile kullanıcıdan veri alma
